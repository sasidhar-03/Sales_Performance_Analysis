# Sales Performance Analysis

## Project Overview

This project analyzes sales performance across regions, categories, products, and customer segments using Python.

## Objectives

- Analyze sales trends
- Identify top-performing products
- Analyze regional performance
- Study customer segments
- Generate business recommendations

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Features

- Order Information
- Customer Information
- Product Categories
- Regions
- Sales Data

## Key KPIs

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value (AOV)

## Visualizations

- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Top Products Analysis
- Customer Segment Analysis

## Business Recommendations

1. Focus on top-selling products
2. Improve low-performing regions
3. Increase marketing during peak months
4. Promote low-selling products
5. Target high-value customer segments
